# V2 常量计算契约修复（2026-10-25）

## 本次故障与范围

诊断测试已取消客户端业务时间与输出限制。失败仍发生在 `propose_solution` 的本地契约校验，而不是 Token 截断：完整返回的 `evaluate("1/(-1)")` 被误要求提供不存在的变量替换。首次输出的 `evaluate/simplify + expected` 也被契约禁止，导致无必要的纠正请求。

此次只改 V2 计算契约、计算执行、明确步骤引用及提示词。保留模型、思考强度、诊断模式、调用和修复保护、独立复核和发布门禁。部署不变，不增加固定模型调用，不自动重试付费请求。

## 修复

- 常量 `evaluate` 不需要虚构 `variables/substitutions`；存在声明变量时仍必须显式赋值。未知符号、越界、除零及危险表达式仍拒绝。
- `evaluate/simplify` 可以携带 `expected`。该值不是被删除或忽略，而是实际验证的等式断言；错误返回 fail，定义域不明返回 unknown，不能作为图形标量继续执行。
- 求值仍返回真实数值，不把“校验差为0”误作求值结果。原 equivalent/substitute_check 的结果契约不改。
- Patch 不允许删除这些新支持的期望值断言来逃避检查；修复后仍走独立复核。
- 仅将与已有步骤 ID 完全相同且全局唯一的简写规范化为 `Q编号:步骤ID`。不猜拼写、不重排证明、不改变原始输出。规范化后继续执行原来的自证/前向引用校验；未知和歧义引用仍失败。
- 解题接受规范化时记录前后哈希和每项引用变化；原模型 JSON 保留。提示词及生成的 Schema 描述同步更新。

## 验证口径

38 项新增核心测试覆盖常量、期望值正反例、定义域、变量绑定、受限数学子进程、引用范围、Patch 防降级，以及无需追加格式纠正的 PlanSolver。

另新增 5 项 V2 集成测试，使用模型 HTTP 替身，覆盖串行/复用配置、独立复核及真实 Chromium 的标量坐标。完整 CI 结果以提交对应的 Actions 记录为准。

对用户保留的两份真实模型输出进行本地离线回放：均可通过契约与引用校验、各19项数学计划，以及5个小问的页面编译。原图、原始日志和完整模型输出未提交到仓库。当地运行环境对 Chromium `file://` 导航返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此没有把本地浏览器回放写成通过。

以上不是新的付费模型运行，也不是证明整题数学正确。下一次新题仍可能提出真实数学/图形异议；这些不能被本修复绕过。
